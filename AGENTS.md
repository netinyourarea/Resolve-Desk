# ResolveDesk project notes

- Client-side rendered SPA: React 19, TanStack Router (file-based), Tailwind CSS v4, Vite.
- Store ResolveDesk shared site components in `src/components/resolvedesk` and its independent content pages as file-based leaves in `src/routes`, keeping brand and legal content consistent across pages.
- `src/routeTree.gen.ts` is generated by the router plugin; do not edit it by hand.
