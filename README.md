# ResolveDesk

Independent online shopping assistance website. A client-side rendered single-page app built with React 19, TanStack Router (file-based routes), Tailwind CSS v4 and Vite.

## Scripts

- `npm run dev` – start the local dev server (http://localhost:5173)
- `npm run build` – type-check and build to `dist/`
- `npm run preview` – preview the production build
- `npm test` – run unit and route tests

Routes live in `src/routes`; shared site components in `src/components/resolvedesk`.
Hosting must rewrite all paths to `index.html` so deep links work.
